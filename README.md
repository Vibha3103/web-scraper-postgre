
# Web Scraping using Scrapy and PostgreSQL

## Project Overview

This project focuses on extracting book information
from the Books to Scrape website using Python and Scrapy.

The extracted information will be processed and stored
in a PostgreSQL database.

## Technologies Used

- Python
- Scrapy
- PostgreSQL
- Psycopg
- Git
- GitHub

## Data to be Extracted

- Book Title
- Book Price
- Book URL
- Book Rating
- Availability

## Project Workflow

1. Website inspection
2. HTML data extraction
3. Scrapy Spider implementation
4. Pagination handling
5. Data processing
6. PostgreSQL integration
7. Data verification
